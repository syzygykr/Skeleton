# 8차: 접합부 및 입구 통로 수정 (현재 버전)

같은 평면 기준점을 공유하는 벽 끝에 inset을 반영한 모서리 접합부를 생성합니다. 벽 끝의 빈 사분면을 작은 접합 블록으로 메우고, 서로 떨어진 부재나 문 내부를 임의로 이어 붙이지 않습니다. 기둥 상단은 보에 0.012 상대 단위 겹쳐 접촉면 틈을 줄였습니다. verify-model.cjs는 각 접합부와 해당 벽의 실제 메시 사각형 겹침, 기둥과 보의 접촉을 검사합니다.

preview-entrance.png는 수정한 입구 상부 확인 화면입니다. archive-v7에 이전 주요 소스를 보관했습니다. 아래 설명과 다르면 이 설명을 우선합니다.

# 7차: 기증전시실 방향 정합 (현재 버전)

VR 전체 평면과 기증전시실 출입문 너머 중앙 복도를 재확인했습니다. 확대 상단도와 전체 박물관 평면의 방향 차이를 놓친 오류를 수정했습니다. 내부 진열대·매입부·꺾인 벽·책상을 함께 반시계 90도로 회전 정합했습니다. 기존 직사각 범위에 맞춰 좌표를 정규화하므로 실측 회전은 아닙니다.

첨부 이미지 오른쪽 위 개방부는 전체 평면에서 위쪽 중앙 복도 방향 출입구입니다. 이전 동측 외벽의 잘못된 개구부를 제거하고 복도 쪽 출입구를 대응 위치로 이동했습니다. '위쪽'은 모델의 전체 상단 뷰 기준이며 실제 방위의 북쪽이라는 뜻은 아닙니다. 인접 기획전시실과 건물 외곽은 회전하지 않았습니다. verify-model.cjs에 회전 방향·문 위치·잘못된 동측 개구부 제거·중앙 진열부 비중첩 검사를 반영했습니다. archive-v6에 이전 주요 소스를 보관했습니다. 아래 과거 설명보다 이 설명을 우선합니다.

# 6차: 기증전시실 확대 상단도 반영 (현재 버전)

사용자가 제공한 reference-donated-plan.png를 기존 전체 평면의 기증전시실 좌표에 대응했습니다. 참조 그림의 가로 58~560, 세로 46~464 범위를 기존 x=988~1145, z=255~414에 대응하는 비율로 읽었으며 실측 환산은 아닙니다. 그림이 잘린 우측 바깥 공간은 추가하지 않았습니다.

수정: 잘못된 동·남측 연속 매입부와 중앙 독립 돌출벽을 제거하고, 중앙 상부 세로 매입 진열부·옆의 좁은 진열대·그 아래 정사각 진열대, 북측 가로 진열대, 좌하단 긴 매입부, 하단 책상·작은 진열대·우하단 가로 진열대를 재배치했습니다. 좌상단 꺾인 구획벽을 추가하고 상부 진입부 및 우측 상부 개방 구간을 조정했습니다. 높이는 상단도에서 판독할 수 없어 이전 VR 기반 근사값을 유지했습니다. 전시품은 생성하지 않았습니다.

verify-model.cjs에서 중앙 세로부와 정사각대의 비중첩, 서측 진열부의 하부 배치 및 폐기한 매입부 제거를 검사합니다. verify.cjs는 preview-donated.png로 확대 상부 화면을 저장합니다. archive-v5는 이전 버전 보관본입니다. 과거 설명과 다르면 이 설명을 우선합니다.

# 5차 수정 (현재 버전)

벽 낮추기는 group=wall에만 적용합니다. 진열대·책상·유리·기둥·상부 보·활 모양 천장·아치는 원래 높이를 유지하며, 체크한 천장도 자동으로 숨기지 않습니다. verify.cjs에서 248개 이상의 부재 변환행렬을 비교하여 비벽체가 움직이지 않는지 검사합니다.

전체 보기 카메라 거리를 반경의 2.5배에서 1.8배로 줄여 화면상의 모델 크기를 약 39% 확대했습니다. 실제 좌표 비율이나 건축 치수 자체를 확대하지는 않았습니다.

입구 책상은 유리 출입부 안쪽으로 이동하고 가로 방향 L자 배치를 조정했습니다. 체험마루 옆 긴 작업대는 중앙 구조물 쪽 벽으로 옮겼으며 뒤쪽 실벽을 추가했습니다. 이전 좌표는 잘못된 근사였습니다.

기증전시실을 VR의 3개 방향으로 회전 관찰하여 매입부 뒷벽·측벽·상인방·하부벽·선반·전면 유리를 분리 생성했습니다. 독립형 유리 상자 3개와 근거가 불충분했던 기획전시실 남측 진열장은 제거했습니다. 내부 돌출벽과 부천활박물관 화살 진열부·상부 영역 매입부도 추가했습니다. 정확한 평면 치수와 일부 대응 위치는 여전히 상대 비율 근사이며 모든 전시실의 완전한 실측 복원을 뜻하지 않습니다. 전시품은 제외합니다. archive-v4는 이전 주요 파일 보관본입니다. 아래 과거 버전 설명보다 이 설명을 우선합니다.

# 4차 상세 추가 (현재 버전)

사용자 요청에 따라 이전의 전시대 제외 원칙을 이번 버전에서 변경했습니다. details.js에 입구 책상·유리 출입부, 활 모양 상부 장식과 가로 부재, 영상실 방향 동선 아치, 야외 방향 작은 유리문, 빈 전시대 16개를 추가했습니다. 전시품·활·모형·인쇄물·화면 콘텐츠는 생성하지 않습니다. 벽 질감은 추가하지 않았습니다.

VR에서 입구 카운터와 유리문, 중앙 목재 상부 구조, 체험마루 옆 통로의 작업대와 유리문, 기증전시실의 유리 진열장, 상부 전시 영역의 벽면 진열대를 확인하고 사진과 대조했습니다. 활 모양 장식과 아치는 곡선 메시로 근사했으며 전시대의 개수·위치·폭은 사진에서 분간 가능한 그룹 단위로 단순화했습니다. 모든 전시대를 실측한 완전 복제본은 아닙니다. 쪽문의 남측 벽상 위치와 입구 유리 전실의 평면 대응도 근사입니다. 영상실 문 뒤의 미공개 내부에는 전시대를 추가하지 않습니다.

상세 요소는 details, 빈 전시대는 displays 체크로 개별 표시합니다. 유리면 체크는 건물과 진열장 유리를 함께 제어합니다. archive-v3에 수정 전 주요 파일을 보관했습니다. 아래는 3차 구조 버전의 설명이며 제외 대상과 파일 목록은 이 4차 설명을 우선합니다.

## 이번 변경

2026-10-28 Matterport VR(https://my.matterport.com/show/?m=B8d8EBTDFq3)에 다시 접속하여 영상실 양개문 앞, 부천활박물관 내부, 확대 미니어처 및 평면도를 대조했습니다.

영상실 앞 공간과 부천활박물관 사이의 짧은 직선 벽을 제거하고, 서측 외벽에서 이어지는 벽·영상실 쪽 완만한 곡면·양끝 돌출부·동쪽 끝의 돌아가는 부분을 하나의 폐합 메시로 구성했습니다. 벽은 x=292에서 끝나며 동쪽 전시공간 연결 통로는 열려 있습니다. 영상실 양개문과 문틀도 추가했습니다. 문은 VR과 같이 닫혀 있으며 문짝 표시를 끄면 개구부가 보입니다. 곡면은 여러 짧은 구간으로 근사했습니다.

실내 외곽을 `envelope`의 18개 선분으로 정의하고, `shell`에 모든 외벽 구간을 연결했습니다. 기존 외벽의 일부 조각을 중복해서 남기지 않았습니다. 체험마루 유리문, 서측 유리 출입부, 영상실 양개문, 동측 출입문은 벽을 통째로 채우지 않고 개구부와 문짝/유리로 표현했습니다. 야외체험장은 실내 외피에서 제외하여 둘레에 벽을 두르지 않았습니다.

## 확인 범위와 추정

외벽의 연결은 완성했지만 실측 외벽 복원은 아닙니다. 기존 단일 바닥의 직각 외곽과 사진의 상대 비율을 기준으로 삼았으며, 스캔이 가려진 외곽은 이어지는 벽선으로 보간했습니다. 각 구간의 `evidence`에 확인·보간 근거를 기록했습니다. 서측 유리 출입부는 VR에서 확인했으나 정규화된 외곽선상의 위치와 폭은 추정입니다.

영상실 표찰이 붙은 양개문 뒤 내부는 VR에서 확인되지 않습니다. 모델의 '영상실 앞 공간'은 문 앞의 실제로 관찰 가능한 공간이며, 문 뒤에 임의의 방을 추가하지 않았습니다. 분리벽의 곡률·깊이·돌출부 치수와 모든 높이·두께는 상대 비율에 따른 근사입니다.

좌표는 상단 사진 1228×612 픽셀 기준, 원점 (650,340), 배율 0.035입니다. X는 오른쪽, Z는 아래쪽, Y는 위쪽이며 미터 단위가 아닙니다. 바닥은 기존 단일 높이·단일 색상·직각 윤곽을 유지합니다. 야외도 같은 높이입니다. `rooms`는 공간 이름과 카메라 중심용이며 정확한 실 경계가 아닙니다.

벽 질감, 전시대, 전시품, 전시용 목재 격자와 안내 패널은 포함하지 않았습니다. 전체 지붕과 미확인 실도 추가하지 않았습니다. 선택 천장은 VR에서 직접 확인한 체험마루·기획전시실만 표시합니다.

## 조작

드래그 회전, Shift 또는 오른쪽 드래그 이동, 휠 확대, Home 전체 보기입니다. 상단·정면·양측면과 '영상실 경계' 전용 관찰 버튼을 제공합니다. 공간 버튼으로 해당 영역에 접근합니다. 벽체·문틀/문짝·기둥/보·유리면·공간 이름을 따로 표시할 수 있습니다. 벽 낮추기는 벽·문·보·유리를 함께 축소하며 천장은 숨깁니다.

## 파일과 검증

- `layout.js`: envelope, shell, 내부 walls, 사용자 정의 solidWalls, 보·기둥·천장·근거.
- `geometry.js`: 벽 개구부, 문짝, 유리 프레임 및 다각형 돌출 메시 생성.
- `viewer.js`: WebGL2·투명 유리·카메라·표시 전환. baseline의 demo.js와 controls.js 재사용.
- `verify-model.cjs`: 면적·법선 방향·삼각분할·ID·치수·문 개구부·외피 18구간 폐합·분리벽 메시·동쪽 통로 막힘 검사.
- `verify.cjs`: 실제 Edge WebGL2 렌더링·GL 오류·6개 시점·표시 전환·공간 이동·Home·모바일 폭 검증.
- `preview.png`, `preview-top.png`, `preview-partition.png`, `preview-ceilings.png`: 검증 화면.
- `archive-v1/`, `archive-v2/`: 이전 주요 소스 보관용. 독립 실행 폴더가 아닙니다.

`node verify-model.cjs`로 모델 데이터를 검증합니다. `node verify.cjs`는 개발 환경에 Playwright와 Edge가 필요합니다. Playwright 패키지는 PLAYWRIGHT_PATH 환경 변수로 지정할 수 있습니다. 코드·메시의 정상 동작 검증은 실제 건축 치수의 정확도 검증과 다릅니다.
