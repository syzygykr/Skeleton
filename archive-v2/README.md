# 박물관 구조 모델 · 2차

`index.html`을 Chrome 또는 Edge에서 열면 실행됩니다. 외부 라이브러리·빌드·텍스처 다운로드가 필요하지 않습니다.

## 현재 단계

바닥, 벽체, 출입 개구부와 문틀, 체험마루 유리문, 긴 전시 영역의 상부 보와 지지 부재를 구성했습니다. 체험마루·기획전시실의 천장은 선택 표시합니다. 질감과 전시대는 다음 단계이며 현재 모델에 포함하지 않습니다.

상단·정면·양측면 사진 4장과 https://my.matterport.com/show/?m=B8d8EBTDFq3 의 공개 미니어처 및 실내 화면을 대조했습니다. 체험마루의 넓은 입구와 야외 방향 유리문, 기획전시실의 문틀 있는 출입부 및 두 실의 천장은 실내 보기로 확인했습니다. 전체 VR 스캔의 원본 메시를 추출하거나 실측한 모델은 아닙니다.

## 조작

- 드래그 회전, Shift+드래그 또는 오른쪽 드래그 이동, 휠 확대, Home 전체 보기.
- 상단·정면·양측면 버튼으로 참고 방향 검토.
- 공간 버튼으로 해당 영역에 접근.
- 벽체, 문틀, 기둥·보, 유리면, 공간 이름을 개별 표시 전환.
- 천장은 기본 숨김. 확인한 두 실의 근사 천장만 표시.
- 벽 낮추기는 문틀·보·유리도 함께 축소하여 평면을 확인. 천장은 자동 숨김.

## 데이터와 근거

`layout.js`가 모든 건축 데이터이며 렌더링 로직과 분리되어 있습니다. 각 부재는 id, 위치, 치수, evidence를 갖습니다. 개구부에는 위치·높이와 근거 설명이 있습니다. 보와 기둥은 각각 beams, columns, 유리문은 frames, 천장은 ceilings에서 수정합니다. 재료는 모두 단색이며 부착 전시 이미지도 제거했습니다.

기준 좌표는 원본 상단 이미지의 1228×612 픽셀입니다. X는 오른쪽, Z는 아래쪽, Y는 위쪽입니다. 원점 (650,340), 배율 0.035이며 미터 단위가 아닙니다. 벽 높이 2.8과 두께 0.16, 문 치수, 보 위치·크기, 유리문 분할 수는 상대 비율에 따른 근사입니다. 확인된 부재의 존재와 추정 치수를 구분합니다.

1차 결과물의 직각 외곽·동일 높이·단일 색상 통합 바닥은 유지합니다. 따라서 바닥은 실제 외벽 경계나 단차 측량 결과가 아닙니다. 야외 부분도 같은 평면입니다. rooms 다각형은 이름과 카메라 위치용이며 실제 벽 경계를 뜻하지 않습니다.

검은 스캔 누락부, 디오라마 곡면, 목재 전시 격자, 진열장, 안내판, 전시 패널을 임의의 건축 부재로 채우지 않습니다. 영상실 인근의 정확한 실 경계, 가려진 외벽, 야외 전체 범위, 문짝 상세, 실제 단차와 전체 지붕은 미확정입니다. 이 모델은 확인 범위의 구조 검토본이며 완전한 실측 건축 모델을 의미하지 않습니다.

## 파일과 검증

- layout.js: 건축 데이터·근거·보류 항목.
- geometry.js: 바닥/천장 삼각분할, 벽 개구부, 문틀·보·기둥·유리 메시 생성.
- viewer.js: WebGL2 렌더링·반투명 유리·시점·표시 전환.
- demo.js, controls.js: baseline의 공통 도구와 트랙볼 재사용.
- verify.cjs: Edge의 실제 WebGL2, GL 오류, 시점·표시 전환·Home·모바일 폭 검증.
- verify-model.cjs: 바닥 면적·삼각분할, 부재 치수, 중복 ID, 출입구 폭 검증.
- archive-v1/: 수정 전 주요 소스 보관용이며 독립 실행 폴더가 아닙니다.
- preview.png, preview-top.png, preview-ceilings.png: 검증 시 생성한 화면.

`node verify-model.cjs`, `node verify.cjs`로 확인합니다. 브라우저 검증에는 개발 환경의 Playwright와 Edge가 필요합니다. Playwright는 PLAYWRIGHT_PATH 환경 변수로 지정할 수 있습니다. 구조의 실제 치수 정확성까지 자동 검증하는 것은 아닙니다.
