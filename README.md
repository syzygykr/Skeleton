# 부천활박물관 WebGL2 · 현재 버전

상단·정면·양측면 이미지와 Matterport VR을 참고한 박물관 공간 모델입니다.
루트 파일이 실행 버전이며 `archive-v*`는 과거 소스 보관본입니다.

## 실행

`index.html`을 WebGL2 지원 Edge 또는 Chrome에서 엽니다. 빌드·서버·외부 다운로드 없이 실행합니다.
목재 텍스처는 로컬 실행을 위해 `assets/textures/texture-assets.js`에 데이터 URI로 포함되어 있습니다.

## 관람 화면

- **평면도**: 정확한 탑뷰의 직교투영.
- **둘러보기**: 주시점 중심의 외부 관찰. 벽 통과 가능.
- **1인칭**: 눈높이 1.575, 카메라 중심 회전. 벽·문·유리·기둥·전시 시설과 몸체 충돌.
- 둘러보기에서 구역 이름표를 누르면 해당 구역의 안전 진입점까지 550ms 동안 이동합니다.
  평면도 이름표는 클릭할 수 없습니다. 1인칭 이름표는 높이 1.85에 표시됩니다.
- 오른쪽 패널은 관람 방식 세 버튼과 전시물 설명용 빈 `exhibit-info` 영역으로 구성됩니다.
  예전 시점 목록·공간 목록·표시 체크박스는 현재 UI에 없습니다.
- PC·태블릿·모바일 모두 화면 너비를 모델 75%, 오른쪽 패널 25%로 나눕니다.
  좁은 패널 안에서는 버튼을 세로로 배치하며 패널 내용은 내부 스크롤합니다.
  버튼 글자는 max(14px,1.05vw), 최소 높이는 max(48px,5vh)로 화면과 함께 확대합니다.
  토글도 최소48×64px를 확보하고 큰 화면에서는 뷰포트에 비례합니다.
  모바일도 상단 바가 아닌 오른쪽 패널을 사용합니다.

## PC·모바일 조작

- 1인칭 이동은 미리 정한 대표점 클릭·터치로 통일합니다. WASD·조이스틱·Shift 자유 클릭·모바일 자유 바닥 탭 이동은 제거했습니다.
- PC는 커서를 표시하고 좌클릭 드래그로 시선을 회전합니다. 모바일도 드래그로 시선을 회전합니다. 상하 범위 ±45도입니다.
- 대표점 클릭 시 A* 충돌 회피 경로를 따라 빠르게 수평 이동합니다. 좌표는 navigation-points.js에서 관리합니다.
- 3인칭 WASD·드래그·휠, 모바일 회전·두 손가락 이동·핀치, 패널 숨김·복원은 유지합니다.
- 자세한 동작은 [WAYPOINTS.md](WAYPOINTS.md)를 참고하세요.

## 모델·재질 범위

- 단일 높이의 직각 외곽 통합 바닥, 실내 외피 22구간, 내부 벽·문·유리·기둥·보.
- 로비의 곡면 분리벽, 중앙 안쪽 꺾임을 가진 활 모양 목재 격자·아치·책상·작업대, 빈 진열장·전시대.
- 아치 오른쪽 기둥 옆 홈부터 작업대 뒤 벽까지 ㄱ자 벽으로 연결하며 기둥 전면은 노출합니다.
- 주 전시실의 목재 테이블 2개와 진열부, 오른쪽 끝의 기단(0.45)+통유리 대형 진열장(상단2.48·돌출1.15), 별도 실감형체험장과 막힌 뒷면의 전시 홈.
- 실감형체험장은 사용자 지정 직사각 확장 구역(X818~1056, Z24~175)입니다.
- 야외체험장은 사용자 지정 확장 마당이며 낮은 경계벽 높이는 0.63입니다.
  서측 쪽문은 열린 통로이며 양방향 이동할 수 있습니다.
- 체험마루는 기존 목재 텍스처를 유지하고, 나머지 실내 바닥은 중앙 로비·영상실과 같은 파란색으로 통일합니다.
- 야외체험장에만 외곽과 같은 높이0.002의 잔디 받침면과 짧은 잔디 잎 메시를 적용합니다. 실내로 번지지 않으며 보행·바닥 탭 이동을 막지 않습니다.
- 관찰 기반 절차적 도장 벽·목재 마감과 걸레받이.
  전시품·모형·부조 작품·설명 인쇄물·영상 콘텐츠는 생성하지 않습니다.
- 재질 근거와 근사 범위는 [VR-MATERIALS.md](VR-MATERIALS.md)에 기록합니다.
- `surfaces.js`는 겹친 공면을 잘라내어 중복 표시를 줄입니다. 정상 접합 부피·충돌 데이터는 유지합니다.

## 좌표·제약

원본 상단 이미지 1228×612 픽셀, 원점 (650,340), 배율 0.035입니다.
X는 이미지 오른쪽, Z는 아래쪽, Y는 위쪽이며 실제 방위·미터 단위가 아닙니다.
높이·두께·개구부 치수·가려진 외벽 연결은 상대 비율 근사입니다.
영상실 양개문 뒤 미확인 내부와 전체 지붕은 생성하지 않았습니다.
관찰 기반 복원과 사용자 지정 확장 영역을 실제 건물의 실측 형상으로 해석하지 않습니다.

## 검증

- `node verify-controls.cjs`, `node verify-model.cjs`: 조작·충돌·공간·메시 검사.
- `node verify-surfaces.cjs`: 중복 표면 검사 및 `surface-cleanup-results.json` 갱신.
- `node audit-overlaps.cjs`: 원본 부재의 체적·공면 교차 보고서 생성.
- `node verify.cjs`: Edge UI·WebGL 회귀 검사 및 미리보기 갱신.
- `node verify-mobile.cjs`: 모바일 터치·동시 입력·세로/가로 레이아웃 검사.
- `node verify-waypoints.cjs`, `node verify-room-labels.cjs`, `node verify-materials.cjs`: 바닥 이동·이름표·재질 검사.
- `node verify-layout.cjs`: PC/모바일 여러 화면 크기에서 75:25 비율·넘침 검사.

브라우저 검사는 Playwright와 설치된 Edge가 필요합니다. 필요하면 `PLAYWRIGHT_PATH`에 패키지 경로를 지정합니다.
자동 검사 통과는 실제 건물 치수의 정확도나 iOS/Android 실기기의 조작감 검증을 뜻하지 않습니다.

## 공통 방향키 이동
1인칭은 PC·모바일 모두 화면 하단의 네 방향 버튼으로 이동합니다. 시선 기준 방향에 있는 가까운 안전 이동점을 선택하며, 이동점 직접 클릭 대신 이 버튼을 사용합니다. `directional-navigation.js`가 공통 방향 선택과 버튼을 담당합니다. 평면도에는 검토 번호를 유지합니다. `node verify-directional-navigation.cjs`로 PC 클릭·모바일 터치·시선 방향 변경·모드 전환을 검사합니다.
