# 박물관 WebGL2 모델 · 14차

상단·정면·양측면 이미지와 Matterport VR을 참고한 박물관 공간 모델입니다.
현재 실행 코드는 이 폴더의 파일이며 `archive-v1`~`archive-v13`은 과거 소스 보관본입니다.

## 실행

`index.html`을 Edge 또는 Chrome에서 엽니다. WebGL2 지원이 필요하며 빌드·외부 다운로드·서버는 필요하지 않습니다.

## 구현 범위

- 단일 높이·단일 색상의 직각 외곽 통합 바닥. 야외 표시 영역도 같은 높이입니다.
- 실내 외곽 18구간의 연결 외벽, 내부 벽, 문틀·문짝, 유리면, 기둥·상부 보.
- 영상실 앞 공간과 부천활박물관 사이의 곡면·돌출 분리벽 및 동측 열린 통로.
- 체험마루의 넓은 출입부와 야외 방향 유리문, 기획·기증전시실 경계와 출입부.
- 입구 안내 책상, 둥근 모서리 작업대, 목재 상부 격자·아치, 빈 전시대·매입 진열부.
- 상부 전시 영역의 양면 목재 테이블 2개, 대형 빈 받침, 외벽 진열부.
- 실감형체험장을 별도 공간으로 구획. 서측 출입구와 막힌 뒷면을 가진 전면 전시 홈.
- 체험마루·기획전시실 천장은 선택 표시.

전시품·모형·부조 작품·족자·설명 인쇄물·영상 콘텐츠·벽 텍스처는 포함하지 않습니다.
현재 범위에는 빈 전시 시설과 책상이 포함됩니다.

## 조작

PC 조작은 명시적 플래그 `controls.state.mode`로 구분합니다. 위치나 확대 배율만으로 모드를 자동 변경하지 않습니다.

| 모드 | 방향키 회전 | 벽 충돌 | 시작 시선·높이 |
|---|---|---|---|
| 외부 관찰 (exterior) | 주시점 중심 | 없음 | 전체·구역 관찰 시점 |
| 내부 1인칭 (interior) | 카메라 제자리 | 벽·닫힌 문·유리·기둥에 적용 | 수평, 문 높이 2.1의 3/4인 1.575 |

- 스페이스바 또는 모드 버튼: 외부/내부 전환. 자동 반복 입력은 무시하고 키 상태를 초기화합니다.
- 첫 내부 진입은 표시된 서측 입구 대기 공간 (125,430)에서 부천활박물관 유리 출입문 (205,366.5)을 바라보는 수평 시선입니다. 좌표는 참고 이미지 기준 근사입니다.
- 내부 재진입은 마지막 위치·좌우/상하 시선·FOV를 복원합니다. 시점 버튼이나 Home으로 외부로 나가도 내부 상태는 보존됩니다.
- 외부 모드 버튼·스페이스 전환은 직전 외부 시점을 복원합니다. Home·관찰 시점 버튼은 지정 외부 시점으로 돌아갑니다.
- 공간 버튼: 외부에서는 공간을 관찰하고, 내부에서는 해당 공간의 안전한 위치로 이동합니다.
- 화면 클릭 후 WASD: 시점 기준 바닥과 평행하게 이동합니다. 외부는 기존 대비 1.5배 속도,
  내부는 확대율과 무관하게 초당 3 상대 단위입니다(이전 내부 속도의 2배).
- 방향키 좌우: 무제한 회전. 내부는 오른쪽 키로 오른쪽, 위쪽 키로 위를 봅니다. 상하는 수평 기준 위·아래 각 60도입니다. 외부는 수평~탑뷰입니다. 외부는 회전 입력이 이동·확대보다 우선하며, 내부는 WASD 이동과 방향키 회전을 동시에 적용합니다.
- 외부의 정확한 탑뷰만 직교투영이며 조금이라도 기울면 원근투영으로 돌아갑니다. 내부는 항상 원근투영이고 수직 시선에 도달하지 않습니다.
- 휠 / + / −: 외부는 거리 조절, 내부는 위치를 유지한 FOV 확대/축소(25~75°)입니다.
- 내부 충돌은 이동 선분 전체를 검사하고 벽을 따라 미끄러집니다. 열린 문은 통과할 수 있습니다.
  낮춘 벽이나 숨긴 벽도 원래 구조 기준으로 충돌하며, 전시대·진열장·책상·작업대도 몸체 높이 범위로 충돌 검사합니다. 둥근 사용자 정의 작업대는 경계 상자로 근사하며, 머리 위 격자·아치는 이동을 막지 않습니다.
- 상부 전시 영역 전용 시점은 관련 구역을 집중 표시합니다.
- 벽·문틀/문짝·기둥/보·상세·전시대·유리·천장·공간 이름은 각각 표시 전환할 수 있습니다.
- 벽 낮추기는 벽체만 축소합니다. 비벽체와 선택한 천장은 유지됩니다.
- 모바일 조작은 미정이며 터치 이동·회전·핀치는 구현하지 않았습니다.

## 좌표와 제약

상단 이미지 1228×612 픽셀의 평면 좌표를 사용합니다. 원점은 (650,340), 배율은 0.035이며,
X는 이미지 오른쪽, Z는 아래쪽, Y는 위쪽입니다. 실제 방위·미터 단위가 아닙니다.
기본 벽 높이 2.8, 두께 0.16 및 개별 상세 치수는 상대 비율에 따른 근사입니다.

외벽의 가려진 구간은 정규화된 직각 외곽으로 보간했습니다. 전체 외벽과 실내 치수의 실측 복원은 아닙니다.
영상실 양개문 뒤의 미확인 내부와 전체 지붕은 생성하지 않았습니다. 야외 둘레에는 건물 외벽을 두지 않습니다.
`rooms`는 공간 이름·카메라 중심용이며 정확한 실 경계는 벽 데이터로 확인합니다.

## 검증

`node verify-controls.cjs`는 시점 기준 이동, 회전 우선순위, 각도 제한, 연속 회전, 휠과 포커스 해제를 검사합니다.

이 폴더에서 `node verify-model.cjs`를 실행합니다. 메시 면적·삼각분할·법선 방향, ID·치수,
외피 폐합, 문·통로 여유, 벽 접합, 기둥·보 접촉 및 주요 상세 배치를 검사합니다.

`node verify.cjs`는 Playwright와 설치된 Edge가 필요합니다. 필요하면 `PLAYWRIGHT_PATH` 환경 변수에
Playwright 패키지 경로를 지정합니다. WebGL 오류·시점·표시 전환·벽 낮추기·공간 이동·Home·모바일 폭을
검사하고 `preview*.png`를 갱신합니다. 자동 검사 통과는 실제 건축 치수의 정확성 검증을 뜻하지 않습니다.
