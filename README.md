# 박물관 Skeleton

`index.html`을 Edge 또는 Chrome에서 열면 실행됩니다. 외부 다운로드, 빌드,
모듈 서버, 텍스처 이미지가 필요하지 않습니다. 모든 실행 파일은 이 폴더 안에 있습니다.

## 조작

- 드래그: 트랙볼 회전. Shift+드래그 또는 오른쪽 드래그: 평행 이동.
- 휠 / + / -: 거리 조절. 방향키: 회전. Home: 전체 보기.
- 상단: 직교 평면 검토. 정면·양측면: 참고 화면 방향에 대응하는 근사 시점.
- 공간 버튼: 해당 바닥 영역 중심으로 이동.
- 벽·프레임·공간명 표시 전환, 벽 낮추기 지원.

## 파일 구성

- `layout.js`: 공간 다각형, 벽의 양 끝점, 벽의 개구부, 프레임, 근거와 보류 항목.
- `geometry.js`: 오목한 바닥의 삼각분할, 벽과 개구부 주변 부재 생성.
- `viewer.js`: WebGL2 렌더링, 카메라 프리셋, HTML 공간명, UI.
- `controls.js`: 제공 예제의 쿼터니언 트랙볼 원본. 박물관 Home은 viewer에서 설정.
- `demo.js`: 제공 예제의 WebGL·행렬·메시 공통 도구 원본.
- `style.css`, `index.html`: 화면 구성.
- `verify.cjs`: 개발 검증 스크립트. 검증 시에만 Playwright와 설치된 Edge 필요.
- `preview.png`, `preview-top.png`: 브라우저 렌더링 확인 이미지.

## 좌표와 근거

평면은 상단 참고 이미지의 1228×612 픽셀 좌표를 기준으로 수작업 단순화했습니다.
X는 이미지 오른쪽, Z는 이미지 아래쪽, Y는 위쪽입니다. (650,340)을 평면 원점으로
사용하며 1픽셀=0.035 상대 단위로 변환합니다. 실제 미터 환산값이 아닙니다.

바닥은 사용자 요청에 따라 Y=0의 단일 연속 메시·단일 색상으로 통합했습니다.
모든 외곽 선분은 X/Z축에 평행하고, 모서리는 직각 또는 안쪽으로 꺾이는 직각입니다.
전시실·연결 영역 사이의 틈과 야외 표시 영역 연결부를 메웠으며, 전시실별 바닥 색상과
재료 구분은 제거했습니다. `layout.js`의 `floor`가 실제 바닥을 정의하고 `rooms`는
공간 이름과 카메라 이동 위치에만 사용됩니다. 이는 요청에 따른 형상 단순화입니다.

벽 높이 2.8, 두께 0.16 및 개구부 치수는
관찰 검토를 위한 임시값입니다. 스캔에 드러난 벽면 구간만 단순화했고, 실제 외벽의
전체 폐합·천장·지붕·기둥 배치를 추정해 채우지 않았습니다. 바닥의 외곽선 또한
스캔에서 확인된 영역의 초안이며 실제 건물 외벽선이나 정확한 실 경계가 아닙니다.

벽 데이터의 `evidence`, 개구부의 `note`, 각 공간의 `note`를 함께 검토해 주세요.
특히 영상실 문은 문의 존재가 보이는 측면과 상단 위치를 잠정 대응한 것이므로
정확한 위치와 폭 검토가 필요합니다. 기획전시실 개구부와 체험마루 개방부도 치수는
확정값이 아닙니다. 유리면은 불투명 벽으로 막지 않고 근사 프레임으로만 표시했습니다.
유리 프레임의 개수·간격 역시 세부 실측값이 아닙니다.

전시품, 진열장, 전시대, 설명판, 영상, 전시용 목재 격자는 포함하지 않았습니다.
체험마루를 포함한 모든 바닥은 같은 색상입니다. 야외도 동일 평면에 연결했습니다.

## 검증

벽·프레임도 직각 바닥의 X/Z 방향에 정렬했습니다. 외곽 벽은 `inset`으로 두께의
절반만큼 안쪽에 배치해 바깥 면을 바닥 끝선에 맞춥니다. 내부 벽은 전시실 경계에
맞추고, 기획전시실 동측/기증전시실 서측의 중복 벽은 공통 경계 하나로 통합했습니다.
전체 외곽을 새 벽으로 닫지 않고 기존에 표시한 구간만 정렬했습니다.

`node verify.cjs` (Playwright 설치 환경), 또는 `PLAYWRIGHT_PATH` 환경 변수에
Playwright 패키지 경로를 지정해 실행합니다. 실제 WebGL2 생성, GL 오류, 시점 버튼,
표시 전환, 공간 이동, Home 복귀, 모바일 가로 넘침과 페이지 오류를 확인합니다.
별도로 geometry.js의 각 바닥이 n-2개 삼각형으로 생성되는지도 점검했습니다.

구조 배치의 실측 정확성을 자동 검증한 것은 아닙니다. 다음 검토에서는 상단 뷰를
기준으로 바닥 비율과 벽 위치를 먼저 수정하고, 이후 높이·단차·문 상세를 조정하세요.
